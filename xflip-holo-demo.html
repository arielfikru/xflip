💡 How it works:
Each layer is a separate image/effect that responds to mouse position. In xflip format, these would be stored as separate chunks (fLyr), with metadata defining blend mode & response curve.
This is a CSS+JS approximation. Real implementation would use WebGL shaders for production-quality effects, but the data structure (multiple layers with metadata) stays the same. The xflip format defines how to store these layers — the rendering engine decides how to display them.
